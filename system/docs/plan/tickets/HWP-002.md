# CI workflow with the four gates and a preview deploy per branch

## Work

- `.github/workflows/ci.yml` on push to `main`, `stable`, `seed` and on pull requests.
- `build` job: checkout, pnpm from `packageManager`, Node 22 with pnpm cache, `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm bugs:check`, `pnpm build`, `pnpm exec playwright install --with-deps chromium`, `pnpm test:browser`, upload `dist`.
- `deploy` job needing `build`, for pushes and same-repository PRs: download `dist`; if `CLOUDFLARE_API_TOKEN` is non-empty run `npx wrangler@4 deploy` on `main`, else `npx wrangler@4 versions upload --preview-alias <alias>` where the alias is the branch lower-cased, non-alphanumerics to dashes, 40 characters; extract the `workers.dev` URL; comment `Preview: <url>` on the PR.
- `wrangler.jsonc`: name `hobby-wizard`, `assets.directory: ./dist`, `not_found_handling: single-page-application`, `preview_urls: true`.

## Acceptance

- The workflow is green on `main` without the Cloudflare secrets (deploy step skipped, job green), and the browser step runs.
- With the secrets present a PR receives one `Preview:` comment with a URL that serves the game.
