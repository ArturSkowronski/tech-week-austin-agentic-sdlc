# Create the repository, secrets and the ticket target

A human does this before Visdom starts M0.

1. Create the public GitHub repository `hobby-wizard` under the organisation, Apache-2.0, default branch `main`.
2. Add repository secrets `CLOUDFLARE_API_TOKEN` (Workers Scripts edit) and `CLOUDFLARE_ACCOUNT_ID`.
3. Decide the repository that receives tickets and set `VITE_GITHUB_REPO` in the CI environment and in the local `.env`.
4. Create the labels `bug`, `planted`, `epic`, and one label per milestone `M0` to `M8`.
5. Grant Visdom's GitHub app write access to the repository.

## Acceptance

Visdom can open a PR against the repository and CI runs on it.
