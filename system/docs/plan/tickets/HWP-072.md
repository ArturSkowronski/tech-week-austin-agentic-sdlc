# Merge policy, auto-merge on green with review approval, human gate for the simulation

## Work

Branch protection on `main`: CI required, one approval required. Visdom's review approval counts. A `CODEOWNERS` entry for `game/sim/**` requiring a human review unless the PR carries the `planted` label and deletes a manifest entry (checked by a small workflow that applies an override label).

## Acceptance

A planted-bug PR merges without a human; any other PR touching `game/sim/` waits for one.
