# Art: the wizard at 2x, every state, crystal visible in every frame

## Human

Generate the eight sheets from the wizard prompt table at 2048 px: idle, run, jump, fall, charge, recoil, hurt, victory. The wizard is on foot in all but the charge and recoil sheets. Record provenance.

## Visdom

Build 64 px cells with `density: 2`; add the recoil, hurt and victory strips to the consumer list in `sprites.ts` and their states to the frame tables in `wizard.ts`.

## Acceptance

Every state has art; the crystal position exists for every frame; a replay shows identical frames twice.
