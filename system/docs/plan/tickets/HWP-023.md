# Wizard animation from state and the crystal light

## Work

- Frame selection per state from `stateTimer` and each state's frame rate; the jump sheet's take-off for four ticks then air up; the fall sheet's flail after 20 ticks; the landing pose from `fellFor`.
- Flip by facing; draw two units below the collision line.
- The additive wand light at the manifest's crystal position for the current frame, mirrored with facing.

## Acceptance

Stepping a replay twice through `window.wizard` yields identical frame indices (exposed on `window.wizard.debug.frame`); the light follows the crystal in every state in screenshots.
