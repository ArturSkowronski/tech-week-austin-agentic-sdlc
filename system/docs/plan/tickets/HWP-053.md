# Raise ticket on GitHub, the prefilled issue, the T key

## Work

`issue.ts` builds the URL `https://github.com/<VITE_GITHUB_REPO>/issues/new` with `title`, `labels=bug,planted` and a `body` with the sections Symptom, Where, Steps, Expected, Actual, Clue, Logs, never the module path. `window.open` is called inside the key or pointer handler.

## Acceptance

Unit test on `issueUrl(bug, state)`: the decoded body contains every section and does not contain the string `game/sim`; Playwright confirms a popup opens on T in the right state and not in others.
