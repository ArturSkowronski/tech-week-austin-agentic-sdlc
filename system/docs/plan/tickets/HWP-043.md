# Art: props at 2x

## Human

Regenerate the prop sheet at 2 px blocks for the props the glade places (bush, log, rock, flag, beacon) and the built torch and sparks, or upscale-clean the 1x set; record provenance. No lantern or mushrooms rows: no room places them (ADR-009).

## Visdom

Teach the prop slicer the density from the sheet's pitch and write `density: 2` entries; update the band mapping for the new sheet; the renderer scales by density so no render change is needed.

## Acceptance

Props render at the same world size as before with twice the detail; strip counts match the asset list.
