# Manifest schema, reader, and the two-way bugs:check in CI

## Work

- `bugs/manifest.json` with an empty `bugs` list and the schema comment.
- `game/sim/bugs.ts`: `PLANTED_BUGS`, `bugsForRoom`, `bugForRoom`.
- `tools/bugs/check.ts`: runs the bugs Vitest config in JSON mode; fails if a listed test passes, if a test file under `bugs/tests/` is not listed and fails, or if a listed test fails on anything but an assertion; prints one line per bug. Repoint the `bugs:check` script at it.

## Acceptance and test

`bugs-check.test.ts` with fixture manifests and tests: fix without delist fails, delist without fix fails, fix plus delist passes, a load error fails with "not an assertion". `pnpm bugs:check` passes with the empty manifest.
