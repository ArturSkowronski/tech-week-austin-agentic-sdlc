# Wizard strips from pose sheets with crystal detection

## Work

Split each wizard raw into columns by empty gaps, resample at its pitch, place each frame bottom-centre in a 32 by 32 cell (40 wide for the fall sheet), find the pale blue crystal's centre per frame and record it, write `sprites/wizard-<state>.png` and the manifest entry with `cell`, `cellW`, `frames`, `crystal`.

## Acceptance

Frame counts match the asset list (idle 4, run 8, jump 7 poses, fall 4, charge 5); every frame has a crystal position; a sheet with an unexpected column count fails the build with a message naming the file.
