# Asset kit raster helpers with unit tests

## Work

`lib.ts` over sharp: load, save as indexed PNG with a palette, block-pitch estimation, resample at block centres, magenta key with purple despill, page-colour key with flood fill from outside, crop, bounding box, run detection, place in cell bottom-centre, horizontal stack, flip, extend bottom with a colour, connected components, resize to height, fill rect.

## Acceptance and test

`lib.test.ts` on synthetic rasters: pitch estimation returns 4 for a 4 px block image and 2 for a 2 px one; keying leaves zero magenta or fringe pixels; components on a three-blob image return three boxes with the right sizes.
