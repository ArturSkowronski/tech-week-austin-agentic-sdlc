# Visdom flow from a labelled issue to a reviewed PR with the gates

## Human

Configure the Visdom project: the repository, the flow triggered by issues labelled `planted`, the four gates plus `pnpm build` as quality gates, the cross-model review-and-fix loop with an iteration limit, and the rule that the review rejects any edit to a file under `bugs/tests/`.

## Visdom

Refine each planted-bug issue with the manifest, the paired test and `AGENTS.md` as context, implement the fix as one PR that corrects the module and deletes the entry, and pass the gates.

## Acceptance

HW-001 goes from issue to a green PR with no human code edits.
