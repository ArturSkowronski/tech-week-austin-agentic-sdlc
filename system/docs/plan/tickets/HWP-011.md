# Swept tile collision, one-way and half-height platforms, ceiling bump

## Work

- `physics.ts`: `moveBox(room, box, dx, dy)` sweeps X then Y in 1-unit steps against the tile grid; returns the new position and which sides hit.
- One-way (`-`) blocks only when moving down and the box's bottom was above the tile's top. Half-height one-way (`=`) has its surface half a tile down.
- Spikes report a `hazard` flag; the caller kills.
- Ceiling contact zeroes upward speed.

## Acceptance and test

`physics.test.ts`: a box moving diagonally into an inside corner ends flush on both axes; a box at full speed never passes through a one-tile wall; from below a one-way is passable, from above it stops. `oneway-half.test.ts`: the `=` surface is eight units lower than `-`.
