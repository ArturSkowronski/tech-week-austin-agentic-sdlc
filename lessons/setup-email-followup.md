Subject: Austin Tech Week, the "software factory" workshop: you can come without the setup

Hi,

a short follow-up before tomorrow. If the setup on your laptop did not work or you had no time,
nothing is lost: the whole workshop runs in the browser, in GitHub Codespaces.

1. Fork https://github.com/ArturSkowronski/tech-week-austin-agentic-sdlc
2. On the fork: Code → Codespaces → Create codespace on main (a 4-core machine).
3. In the codespace's terminal: factory start (about 10 minutes, do it before the workshop).

Codespaces is free for GitHub Free accounts: 120 core-hours a month, which is 30 hours on a
4-core machine. Without a card GitHub simply blocks usage when the quota runs out; it does not
send a bill. Instructions: lessons/start.md in the repo.

For everyone: you can start any lesson from scratch (factory lesson N), check it
(factory check N), and when you get stuck, run the autopilot (factory autopilot N, it starts Claude Code)
or look at the ready variant in solutions/lesson-NN/.
