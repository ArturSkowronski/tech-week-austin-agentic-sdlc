# Scaffold the repository and toolchain

## Goal

An empty Vite app that passes every gate, with the scripts every later ticket relies on.

## Work

- pnpm 11 with `packageManager` in `package.json`, Node `>=22`, `"type": "module"`, licence Apache-2.0.
- Dependencies: `pixi.js` 8. Dev: `typescript` 6.x, `vite` 8, `vitest` 5, `@playwright/test`, `eslint` 10, `@eslint/js`, `typescript-eslint` 8, `tsx`, `sharp`, `@types/node`.
- `pnpm-workspace.yaml` allowing build scripts for `esbuild` and `sharp`.
- `tsconfig.json` strict with `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`, `allowImportingTsExtensions`, `resolveJsonModule`.
- Scripts: `dev`, `trace`, `build` (`pnpm assets && vite build`), `preview`, `assets`, `assets:report`, `test`, `test:watch`, `test:browser` (`playwright test --pass-with-no-tests`), `typecheck`, `lint`, `bugs:check`. Scripts whose tool does not exist yet point at `tools/not-yet.ts`, a stub that exits 0 and prints "not yet"; the ticket that creates the tool repoints the script and lists `package.json`.
- Two Vitest configs: the main one includes `tests/**` and excludes `tests/smoke/**`, the bugs one includes `bugs/tests/**`. Both set `passWithNoTests`.
- `playwright.config.ts`: Chromium only, specs in `tests/smoke/`, a `webServer` that serves the built `dist/` with `vite preview`.
- `index.html` with a single canvas container; `game/main.ts` that mounts nothing yet.

## Acceptance

- `pnpm install --frozen-lockfile && pnpm typecheck && pnpm lint && pnpm test` exit 0 on an empty suite.
- `pnpm build` produces `dist/index.html`; `pnpm exec playwright install chromium && pnpm test:browser` exits 0 with no spec files.
