# Art: props at 2x

## Human

Regenerate the prop sheet at 2 px blocks with the lantern and mushrooms rows added, or upscale-clean the 1x set; record provenance.

## Visdom

Teach the prop slicer the density from the sheet's pitch and write `density: 2` entries; update the band mapping for the new sheet and add `props/lantern` and `props/mushrooms` to it and to the consumer list in `sprites.ts`; the renderer scales by density so no render change is needed.

## Acceptance

Props render at the same world size as before with twice the detail; strip counts match the asset list.
