# Paintings, declared edits, panel stitching, density-2 manifest entries

## Work

For `assets/painting-<room>-<n>.png` (or a single `painting-<room>.png`): apply the declared edits (the ruin gate's bridge cut, a magenta rectangle), key magenta, fit to 704 px tall, posterise, join left to right, write `paintings/<room>.png` and a manifest entry with `density: 2` and the tile extent (width divided by 32).

## Acceptance

`paintings/ruin-gate.png` is 704 tall and 132 tiles wide; the bridge shows open air; the edit list is the only place the cut is described.
