# The trace tool, map model, brushes, auto-trace, save through the dev server

## Work

- `map.ts`: parse, resize, set, fill, serialise keeping the module's header comment, auto-trace from painting opacity coverage per tile.
- UI at `/tools/trace/index.html`: room picker from the glob, painting underlay, brushes for the whole legend and prop footprints, undo, auto-trace button, save.
- Repoint the `trace` script at the dev server opened on the tool.
- Vite dev plugin endpoints `/__trace/room` and `/__trace/painting` that write only inside `game/content/rooms/` and `assets/`, names restricted to `^[a-z][a-z0-9-]*$`.

## Acceptance and test

`trace-map.test.ts`: round-trip of the glade keeps the header and every character; auto-trace of a synthetic painting marks exactly the opaque tiles. A room saved from the tool plays with `?room=`.
