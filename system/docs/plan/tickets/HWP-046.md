# Room transitions in an order table, flag state kept

## Work

`game/content/order.ts`, outside the rooms glob, lists `forest-glade, ruin-gate, cliff-ruins`. Every room keeps its beacon. Touching the beacon of a room that is not last emits a `room:next` event instead of `victory`; the loop loads the next room at its spawn, keeps deaths and the run clock, resets the checkpoint to the new spawn. The last room's beacon is `victory` as before. Room edges stay walls. A room played alone with `?room=` treats its beacon as `victory`.

## Acceptance and test

`transition.test.ts`: touching the glade's beacon in the ordered run yields the ruin gate state at its spawn with `deaths` preserved and the run clock continuing; touching the cliff ruins beacon sets `victory`; `forest-room.test.ts` still passes per room.
