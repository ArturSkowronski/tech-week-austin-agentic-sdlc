# Evidence, the waterfall shows the beat's log lines, the card's four states

## Work

The waterfall reads `bugForRoom(roomName).logs`; the card picks its state from `creature.firstCarried`, whether the room's waterfall has been parted this run, and whether the manifest has a bug for the room; the button shows only in the "logs read and bug felt" state.

## Acceptance

Playwright: before touching anything the card is hidden; after parting the water it reads "The logs mention a bug in input handling. It hides in the bush."; after also being carried it names HW-001 and shows the button, and a screenshot while carried shows the eyes on the hat.
