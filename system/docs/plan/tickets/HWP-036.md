# Build fails on unreferenced kit outputs and on stray files in public/assets

## Work

After building, compare the manifest's outputs with the consumer list: a static list exported from `game/render/sprites.ts`, the renderer's declaration of what it loads, plus painting and landmark names from the rooms glob. Fail on any output not in the list, on any listed name with no output, on any raw in `assets/` that produced no output, and on any file under `public/assets` not in the manifest. Seed the list with every output the kit builds at this point, including `splash`, `props/torch` and `props/sparks`, whether or not the renderer draws them yet. From here on, a ticket that adds an output adds its consumer to the list in the same PR. Repoint the `assets:report` script at `report.ts`, which prints every output with its consumer.

## Acceptance

Adding a raw the kit does not build fails `pnpm build` with its name; removing it passes; removing a name from the consumer list fails the build naming the orphan output; `pnpm assets:report` lists a consumer for every output.
