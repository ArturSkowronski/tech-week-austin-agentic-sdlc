# WorldState, InputFrame, constants, tick skeleton, seeded RNG

## Work

- `state.ts`: the `WorldState` shape from the architecture doc, `Tile` ids, `PlayerState`, `Prop`, `Creature`, `tileAt`, `nextRandom` (a 32-bit xorshift over `state.rng`).
- `input.ts`: `InputFrame { left, right, jump, charge, down }` and `NO_INPUT`.
- `constants.ts`: every value of the tuning table, with a header comment naming the design doc.
- `tick.ts`: `tick(state, input)` that increments `tick`, clears `events`, stores `lastInput`, and calls the player, prop and creature steps (stubs for now).
- `tests/sim/helpers.ts`: `worldFrom(text, options)`, `run(state, frames)`, `hold(input, ticks)`.
- `createWorld(roomText, { seed, creature })`.

## Acceptance and test

`world.test.ts`: two worlds from the same map and seed, stepped with the same 600 frames, are deep-equal; `nextRandom` sequence for seed 1 matches a recorded list of five values. `game/sim/**` imports nothing from `render/`, enforced by an ESLint `no-restricted-imports` rule.
