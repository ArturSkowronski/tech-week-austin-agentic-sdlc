# Pixi application, render texture at density 2, display fit, window.wizard

## Work

- `main.ts`: fixed 60 Hz accumulator, render once per frame, `?room=` selection with the default room, `window.wizard` with `start`, `reset`, `paused`, `step(n, input)`, `state()`.
- `config.ts`: `VIEW_W = 320`, `VIEW_H = 180`, `RENDER_DENSITY = 2`, and every constant the look doc lists, with nothing else owning them.
- `scene.ts`: a 640 by 360 render texture drawn to a sprite scaled by the largest even integer that fits, letterboxed, nearest-neighbour; a full-resolution UI container on top.
- `input.ts`: keyboard sampling into an `InputFrame` with edge flags for start, restart, ticket (T callback) and F1.

## Acceptance and test

Playwright `load.spec.ts`: the page loads, `window.wizard.start()` then `step(60, { right: true })` moves the player right by more than 60 units, and a screenshot has the expected canvas size at a 1280 by 720 viewport (1280 by 720 canvas, scale 4).
